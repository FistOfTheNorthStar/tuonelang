Model a bank account. Define `struct Account { balance: Int }` and `enum Op { Deposit { amount: Int }, Withdraw { amount: Int } }`. Write `apply(in acc: Account, in op: Op) -> Account`: a deposit adds its amount; a withdrawal subtracts its amount only when the balance covers it, and otherwise leaves the account unchanged. Write `run(in ops: [Op; 4]) -> Int` that starts from a zero balance, applies the four operations in order, and returns the final balance.
