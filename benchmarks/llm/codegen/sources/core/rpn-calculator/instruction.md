Write a reverse-Polish calculator. Define `enum Token { Num { value: Int }, Add, Sub, Mul }` and `eval_rpn(in tokens: [Token; 7]) -> Int`, which evaluates the tokens with a stack (a growable `Array[Int]`): a number is pushed; an operator pops the right operand, then the left operand, and pushes left op right. Return the single value left on the stack. Inputs are always well formed.
