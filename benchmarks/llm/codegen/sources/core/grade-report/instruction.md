Write a small grading program. Define `struct Score { student: Int, points: Int }`. Write `letter(take points: Int) -> Int` mapping points to a grade number: 90 and above is 4, 80-89 is 3, 70-79 is 2, 60-69 is 1, below 60 is 0. Write `passing(in scores: [Score; 5]) -> Array[Int]` returning, in input order, the student numbers whose grade is at least 1, and `class_average(in scores: [Score; 5]) -> Int` returning the floor of the mean points.
